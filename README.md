# Workflow Control Layer — Stanislavsky × ClickUp

Прототип интеграции мультиагентной системы кинопроизводства (Stanislavsky) с ClickUp: человек видит работу агентов и может вмешаться на любом этапе.

Собран полностью: контракты, детерминированный роутер, batching-очередь, filter, outbound-очередь с ретраями, 4 мок-агента, sim-харнесс на всех 7 сценариях ТЗ, живой демо-слой на реальном ClickUp API. 92 юнит/сим-теста зелёных, живой раунд-трип подтверждён на настоящей доске.

- **`docs/source/`** — исходные материалы как есть (ТЗ, архитектура, roadmap, Alliance Deck, демо-датасет костюмного цеха v1/v2).
- **`docs/`** — рабочая документация (00-11): архитектура, план сборки, открытые вопросы, живой демо-скрипт.
- **`prototype/`** — код. См. `prototype/README.md` для карты модулей, статуса и запуска.

## С чего начать

1. `prototype/README.md` — карта кода, как запустить тесты и `sim.runner`.
2. `docs/11_live_demo_architecture.md` — как устроен живой раунд-трип на реальном ClickUp (вебхук, echo-фильтр, safety-протокол).
3. `docs/06_open_questions.md` — что осталось уточнить у владельца Stanislavsky перед MVP.
